Preliminares

Antes de empezar: instala Python

Qué es programar: escribir instrucciones paso a paso para que la computadora haga una tarea. La computadora hace exactamente lo que dices, ni más ni menos, así que los errores son normales y parte del aprendizaje.

Instalación

  • Windows/Mac: descarga Python desde python.org. En Windows marca la casilla "Add Python to PATH" antes de instalar.
  • Editor: instala Visual Studio Code y su extensión "Python". Alternativa sin instalar nada: replit.com o Google Colab.
  • Android: la app Pydroid 3 sirve para practicar desde el celular.

Prueba que funciona

Crea un archivo hola.py, escribe esto y ejecútalo (botón ▶ en VS Code, o en la terminal: python hola.py):

print("Hola, mundo")

Si ves Hola, mundo en pantalla, ya eres programador. Lo demás es practicar.

Reglas de oro de la semana: 1) Escribe el código tú, no copies y pegues. 2) Lee el mensaje de error: dice la línea del problema. 3) Practica todos los días, aunque sea poco.

Cómo lee Python tu código

Python es un intérprete: lee el archivo de arriba hacia abajo, una línea a la vez, y ejecuta cada instrucción en ese orden. Si una línea tiene un error, se detiene ahí y te dice el número de línea. Por eso una variable debe crearse antes de usarla.

Explicado con calma

Piensa en un programa como una receta: una lista de pasos que se siguen en orden. print() es la forma en que la computadora te "habla": lo que pongas entre paréntesis aparece en pantalla. Si es texto, va entre comillas; si es un número o una cuenta, va sin comillas y Python la calcula antes de mostrarla (print(2 + 3) muestra 5, mientras que print("2 + 3") muestra literalmente 2 + 3).

Una variable es una etiqueta pegada a un dato. Cuando escribes edad = 18, Python guarda el 18 en memoria y le pega la etiqueta edad. Desde ese momento, escribir edad es lo mismo que escribir 18. Por eso puedes cambiar el valor en un solo lugar y todo el programa se actualiza.

Para recordar: el signo = en programación no significa "es igual a" como en matemáticas. Significa "guarda lo de la derecha en la variable de la izquierda".

Conceptos a fondo

Conversión de tipos

Python no suma texto con número. Debes convertir con int(), float() o str().

print("5" + "3")        # 53 (junta textos)
print(int("5") + int("3")) # 8 (suma números)
print("Edad: " + str(18))  # convertir número a texto

Si el usuario escribe letras donde esperas un número, int() da ValueError. Más adelante aprenderás a controlarlo.

Operadores de asignación abreviados

x = 10
x += 5   # x = x + 5  -> 15
x -= 3   # 12
x *= 2   # 24
x //= 5  # 4

Redondear y dar formato

print(round(3.14159, 2))   # 3.14
pi = 3.14159
print(f"{pi:.2f}")         # 3.14 (2 decimales)
precio = 1500.5
print(f"${precio:,.2f}")   # $1,500.50

Orden de operaciones

2 + 3 * 4 da 14, no 20. Usa paréntesis para controlar: (2 + 3) * 4 da 20. Ante la duda, pon paréntesis.

print: coma o suma

Explicado con calma

Hasta ahora tu programa hablaba solo. Con input() empieza una conversación: el programa se detiene, espera a que la persona escriba y presione Enter, y guarda lo escrito en una variable. Lo más importante que debes memorizar es que todo lo que llega por input() es texto, aunque el usuario escriba 25. Si lo vas a usar en una cuenta, envuélvelo en int() o float().

La división entera // y el residuo % parecen raros al inicio, pero son muy útiles. Si tienes 125 segundos: 125 // 60 son 2 minutos completos y 125 % 60 son 5 segundos que sobran. Es exactamente la división de la primaria: cociente y residuo.

total = 125
minutos = total // 60
segundos = total % 60
print(f"{total} s = {minutos} min {segundos} s")

Los f-strings (la f antes de las comillas) te dejan escribir variables y cuentas dentro de llaves {}. Son la forma más limpia de armar mensajes y evitan errores de tipo.

Receta de un programa típico: 1) pedir datos con input, 2) convertirlos al tipo correcto, 3) hacer el cálculo, 4) mostrar el resultado con un f-string.

Explicado con calma

Hasta ahora todas las líneas se ejecutaban siempre. Con if el programa empieza a decidir. Una condición es una pregunta que se responde con sí (True) o no (False). Si la respuesta es sí, se ejecuta el bloque con sangría; si es no, Python lo salta.

Con elif y else armas una escalera: Python revisa de arriba hacia abajo y entra solo al primer bloque cuya condición sea verdadera. Por eso el orden importa. En el ejemplo de la calificación, si preguntaras primero >= 70, un 95 nunca llegaría a ser "Excelente".

nota = int(input("Calificación: "))
if nota >= 90:
    print("Excelente")
elif nota >= 70:
    print("Aprobado")
else:
    print("Reprobado")

Piensa en and como "los dos deben cumplirse" y en or como "con uno basta". Y recuerda: % te sirve para decidir. Un número es par si n % 2 == 0; es múltiplo de 5 si n % 5 == 0.

Repetir con bucles

Objetivo

Repetir instrucciones sin copiarlas muchas veces.

1. for con range()

for i in range(5):        # 0,1,2,3,4
    print(i)
for i in range(1, 6):     # 1 al 5
    print(i)
for i in range(0, 11, 2): # de 2 en 2
    print(i)

2. while: repite mientras una condición sea verdadera

contador = 1
while contador <= 5:
    print(contador)
    contador += 1   # sin esto el bucle sería infinito
Si se cicla, presiona Ctrl + C en la terminal para detenerlo.

3. Acumuladores

suma = 0
for n in range(1, 11):
    suma += n
print(suma)  # 55

4. break

while True:
    clave = input("Clave: ")
    if clave == "python":
        print("Correcto")
        break

Conceptos a fondo

Cuándo usar for y cuándo while

Usa for cuando sabes cuántas veces repetir (10 veces, una vez por cada elemento). Usa while cuando no lo sabes (hasta que el usuario acierte, hasta que escriba "salir").

Cómo "corre" un bucle (prueba de escritorio)

suma = 0
for i in range(1, 4):
    suma += i
# vuelta 1: i=1, suma=1
# vuelta 2: i=2, suma=3
# vuelta 3: i=3, suma=6
print(suma)  # 6

Seguir el valor de cada variable vuelta por vuelta en papel es la mejor forma de entender un bucle.

range() con detalle

range(inicio, fin, paso): el fin nunca se incluye. range(1, 6) da 1,2,3,4,5. Para contar hacia atrás: range(5, 0, -1).

for sobre textos

for letra in "Python":
    print(letra)

continue y break

for i in range(1, 8):
    if i == 3:
        continue   # salta esta vuelta
    if i == 6:
        break      # termina el bucle
    print(i)       # 1 2 4 5

Bucles anidados

for fila in range(1, 4):
    for col in range(1, 4):
        print(fila * col, end=" ")
    print()

end=" " evita el salto de línea. El bucle de dentro se completa entero en cada vuelta del de fuera.

Errores comunes

  • Bucle infinito: en un while olvidar actualizar la variable (contador += 1).
  • Error por uno: esperar que range(5) llegue hasta 5; llega hasta 4.
  • Poner el print con sangría equivocada y que se repita (o no) cuando no debe.

Explicado con calma

Imagina que debes escribir tu nombre 100 veces. Copiar y pegar sería absurdo; un bucle lo hace en dos líneas. Un bucle ejecuta el mismo bloque una y otra vez, y cada repetición se llama vuelta o iteración.

En un for i in range(1, 6) la variable i toma un valor distinto en cada vuelta (1, luego 2, luego 3...). Tú no la actualizas: Python lo hace solo. En un while, en cambio, tú eres responsable de que la condición algún día deje de cumplirse; si no, el bucle es infinito.

Un patrón que verás toda tu vida es el acumulador: una variable que empieza en 0 (o en 1 si multiplicas) y va juntando resultados vuelta tras vuelta.

factorial = 1
for i in range(1, 6):
    factorial *= i      # 1, 2, 6, 24, 120
print(factorial)        # 120
Ejercicio mental: antes de ejecutar un bucle, escribe en papel una tabla con una columna por variable y una fila por vuelta. Si tu tabla coincide con lo que imprime Python, entendiste el bucle.

Conceptos a fondo

Listas: más herramientas

nums = [30, 10, 20]
print(nums[-1])      # 20 (último elemento)
print(nums[0:2])     # [30, 10] (rebanada, sin incluir el 2)
nums.sort()          # ordena: [10, 20, 30]
nums.insert(1, 15)   # inserta en la posición 1
print(sum(nums), min(nums), max(nums))
print(20 in nums)    # True

Las posiciones (índices) empiezan en 0. Pedir una posición que no existe da IndexError.

Funciones: partes

  • def: palabra para definir la función.
  • Parámetros: los datos que recibe (a, b).
  • Argumentos: los valores reales al llamarla (sumar(3, 4)).
  • return: el valor que entrega y termina la función.
def saludar(nombre, saludo="Hola"):  # valor por defecto
    return f"{saludo}, {nombre}"

print(saludar("Ana"))            # Hola, Ana
print(saludar("Luis", "Buenas")) # Buenas, Luis

Variables locales

Una variable creada dentro de una función solo existe ahí. Si intentas usarla afuera da NameError. Para sacar datos, usa return.

Por qué usar funciones

Evitan repetir código, lo hacen más ordenado y puedes probar cada parte por separado. Regla útil: una función, una tarea.

Errores comunes

  • Olvidar el return y recibir None.
  • Definir la función pero nunca llamarla.
  • Llamarla con menos argumentos de los que pide (TypeError).

Explicado con calma

Una lista es una fila de casilleros numerados desde 0. Es la herramienta para cuando tienes "muchos de lo mismo": nombres, calificaciones, precios. Combinada con for, procesas todos sus elementos con pocas líneas.

Una función es una receta con nombre. La defines una vez con def y la usas cuantas veces quieras. Los parámetros son los ingredientes que pide; return es el platillo terminado que te entrega. Si la función solo hace print, el resultado se muestra pero no puedes guardarlo en una variable; con return sí.

def promedio(lista):
    return sum(lista) / len(lista)

notas = [8, 9, 10, 7]
print(f"Promedio: {promedio(notas):.1f}")  # 8.5

El proyecto final junta casi todo: un número al azar (random), un bucle que no sabes cuánto durará (while), decisiones (if/elif/else) y un contador. Si te atoras, divide el problema: primero haz que pida un número, luego que compare, luego que repita, luego que cuente.

Objetivo

Una clase hija hereda atributos y métodos de la clase padre y puede añadir o sobrescribir los suyos. super() llama al padre. Úsala cuando "A es un tipo de B" (un perro es un animal).

class Animal:
    def __init__(self, nombre):
        self.nombre = nombre
    def hablar(self):
        return "..."

class Perro(Animal):
    def hablar(self):
        return "Guau"

class Gato(Animal):
    def __init__(self, nombre, color):
        super().__init__(nombre)
        self.color = color
    def hablar(self):
        return "Miau"

    print(a.nombre, a.hablar())

Conceptos a fondo

Sobrescribir un método es redefinirlo en la hija. Junto con la herencia permite el polimorfismo: tratar objetos distintos con la misma interfaz (animal.hablar()). Si la hija define __init__, debe llamar a super().__init__() o perderá los atributos del padre.

    def __init__(self):
        self._celsius = 0
    @property
    def celsius(self):
        return self._celsius
    @celsius.setter
    def celsius(self, valor):
        if valor < -273.15:
            raise ValueError("Imposible")
        self._celsius = valor
    @property
    def fahrenheit(self):
        return self._celsius * 9 / 5 + 32

Objetivo

Comprensiones

  • Usar una comprensión solo por sus efectos (como imprimir).

Pilas y colas

Objetivo

Entender estructuras con reglas de entrada y salida.

Una pila es LIFO: el último en entrar es el primero en salir (como un montón de platos). Una cola es FIFO: el primero en entrar es el primero en salir (como una fila). Para colas usa deque, que es rápida en ambos extremos.

from collections import deque
pila = []
pila.append(1); pila.append(2)
print(pila.pop())      # 2

cola = deque()
cola.append("A"); cola.append("B")
print(cola.popleft())  # A

Conceptos a fondo

pop() quita el último elemento de una lista rápidamente, pero pop(0) es lento porque desplaza todo; por eso las colas usan deque. Las pilas se usan en deshacer, navegación y recursión; las colas en turnos y procesos por orden de llegada.

Errores comunes

  • Hacer pop en una pila o cola vacía (IndexError).
  • Usar list.pop(0) para colas grandes.
  • Confundir LIFO con FIFO.

Ejercicios en clase

Día 19

Búsqueda y ordenamiento

Objetivo

Implementar algoritmos clásicos y entender su costo.

La búsqueda lineal revisa uno por uno. La búsqueda binaria divide la lista ordenada a la mitad en cada paso y es mucho más rápida. El ordenamiento burbuja compara pares vecinos e intercambia.

def binaria(lista, x):
    ini, fin = 0, len(lista) - 1
    while ini <= fin:
        medio = (ini + fin) // 2
        if lista[medio] == x:
            return medio
        elif lista[medio] < x:
            ini = medio + 1
        else:
            fin = medio - 1
    return -1

def burbuja(l):
    for i in range(len(l)):
        for j in range(len(l) - 1 - i):
            if l[j] > l[j + 1]:
                l[j], l[j + 1] = l[j + 1], l[j]
    return l

Conceptos a fondo

La eficiencia se expresa con O grande: la lineal es O(n), la binaria O(log n) y la burbuja O(n²). En un millón de elementos la binaria necesita unas 20 comparaciones. Python ya trae sorted() y .sort(), muy optimizados; aprender burbuja sirve para entender el algoritmo.

Errores comunes

  • Usar búsqueda binaria en una lista sin ordenar.
  • Error de uno en los límites (< en lugar de <=).
  • Olvidar que .sort() modifica la lista y sorted() devuelve una nueva.
